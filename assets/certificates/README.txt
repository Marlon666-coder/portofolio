Put certificate images here (JPG/PNG/WebP, landscape ~1.41:1, at least 1600 px wide).
Then add an entry to the certificates list in config.js, for example:

  {
    title: 'Certificate Title',
    issuer: 'Issuing Organization',
    date: 'January 2027',
    credential: 'Credential ID or short description',
    image: 'assets/certificates/certificate-name.jpg',
    url: ''   // optional verification link
  }
